# ai-tech-market-risk
Explainable ML and deep learning system for predicting short-term volatility and abnormal movements in AI and technology stocks.

## Inference API

The FastAPI inference service is in `api/` and exposes:

- `GET /health`
- `GET /model-info`
- `POST /predict`

Before running locally or building the container, restore the trained champion artifact at:

```text
api/artifacts/logistic_regression_candidate.joblib
```

This file is generated by `notebooks/07_fastapi_inference.ipynb` from the model in
`models/`. It is intentionally required at image-build time so an image cannot be
published without the frozen inference model.

Build and run the API from the repository root:

```powershell
docker build -t ai-tech-market-risk-api ./api
docker run --rm -p 8000:8000 ai-tech-market-risk-api
```

Once running, interactive documentation is available at `http://localhost:8000/docs`.
